# 🐰 Code Bunny

A LeetCode-style full stack coding platform for tech bunnies 🥕

## 🚀 Features
- Coding problem editor
- Test case execution
- AI-powered features (Gemini integration)
- User profiles
- Problem listing system

## ⚙️ Tech Stack
- React + Vite
- TypeScript
- Node.js backend
- Firebase
- Gemini API

```bash
npm install
